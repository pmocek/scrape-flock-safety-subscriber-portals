### Policy Overview
* **Prohibited Uses**: Immigration enforcement, traffic enforcement, harassment or intimidation, usage based solely on a protected class (i.e. race, sex, religion), Personal use.

* **Access Policy**: All system access requires a valid reason and is stored indefinitely. SCSO Policy dictates that a search must contain a case or reference number to associate the search with a report or complaint card.
